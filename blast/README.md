# Blast Analysis
## Aim 
To compare the protein sequences from other mammalian species using BLASTP for comparative analysis.

## Tool Used
- NCBI BLASTP

## Parameters used
1. Query cover: % of query sequence that's present in the alignment.
2. % identity: % of identical amino acids or nucleotides between the query and the reference sequence.
3. Bit Score: Indicates the quality of the alignment. 
4. E- Value: Indicates how likely the match could occur by chance.
