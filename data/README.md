# Data
This folder contains the data used in this bioinformatics project.

## Gene Information
- Gene name: ADRB2 Gene
- Full name: Beta-2 adrenergic gene
- Gene type: Protein coding gene
- Pathway involved: GPCR
- Organism: HOMO SAPIENS

## Species Included 
- Homo sapiens (Human)
- Mus musculus (Mouse)
- Rattus norvegicus (Brown Rat)
- Bos taurus (Bovine cow)
- Sus scrofa (Pig)

## Data Sources
- NCBI
- UniProt

## Target
This project is done to compare this gene within different mammalian species and to study conservation and evolutionary relationships.
