# Aim
Phylogenetic tree construction is done to study the evolutionary relationships among the selected species based on their aligned sequences. Here a phylogenetic tree is constructed using the Maximum Likelihood method. The evolutionary distances between the sequences were calculated, and species with greater sequence similarity were grouped into closely related branches. The resulting tree was visualized as a phylogenetic tree.

# Method 
1. The multiple aligned sequences are imported to MEGA.
2. Appropriate model of tree constitution is selected.
3. The tree has been generated and saved as image for further studies.

# Conclusion
- It shows two major evolutionary structures:
  1. Rodent-human cluster: Rat, Mouse, Human
  2. Bovine-Pig cluster: Bovine, Pig
- This whole cluster demonstrates that ADRB2 gene is conserved across these mammalian species but also shows some evolutionary divergence.
- Rat and mouse ADRB2 sequences are most closely related among five sequences as they form very short evolutionary distances.
- Bovine and pig also form another closely related pair.
- The scale bar demonstrate 0.02 substitutions per site. Shorter branches mostly indicate greater sequences similarity while longer branches indicate greater divergence.
